# AI News Daily

Daily AI news — regulation, companies, papers, and breakthroughs.

Built with [Astro](https://astro.build) and the [flo-bit blog template](https://github.com/flo-bit/blog-template).

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Pushed to `main` → GitHub Actions builds and deploys to GitHub Pages.
